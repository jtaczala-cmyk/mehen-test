# Mehen: Droga Węża — WERSJA TESTOWA

Test build of a mobile-first browser board game by Stop60 — a digital adaptation of the
ancient Egyptian spiral game Mehen. Not listed on the public Stop60 pages yet (noindex).

- Single self-contained `index.html` (inline JS/CSS, procedural Canvas graphics and Web Audio, no external assets)
- Modes: vs computer (easy / hard) and 2 players on one phone
- Match is saved only in the browser (localStorage)
- Free, no ads, no payments, no tracking
