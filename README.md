# Hefau – Slangespiralen / Spirala Węża / The Serpent Spiral — TESTVERSJON

Test build of a mobile-first browser board game by Stop60: an original digital game inspired by the
ancient Egyptian spiral board game mehen. Not listed on the public Stop60 pages yet (noindex).

- Single self-contained `index.html` (inline JS/CSS, procedural Canvas graphics, Web Audio, embedded font subsets and QR generator — no external requests)
- Languages: Norsk (bokmål), Polski, English (`?lang=no|pl|en`, default by browser language, fallback Norwegian)
- Modes: vs computer (easy / hard) and 2 players on one phone; "Share the game" with QR code
- Cinematic opening (once per session, skippable), procedural Egyptian music and ambience (lyre/harp, sistrum, frame drum, drone; muted with the sound button)
- App icons (`apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, favicons) and `manifest.webmanifest` for "Add to Home Screen"
- Match is saved only in the browser (localStorage)
- Free, no ads, no payments, no tracking
